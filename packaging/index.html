Hammerhead Control

Native KDE controls for Razer Hammerhead V3 HyperSpeed earbuds.

Download the Debian installer · Source and instructions

Install the downloaded package with sudo apt install ./hammerhead-control_VERSION_all.deb. It configures this signed APT feed automatically.

Update with sudo apt update && sudo apt install --only-upgrade hammerhead-control.
